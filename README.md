# Лабораторная работа №2. Реализация структуры Data Vault

Дисциплина: Хранилища данных
Вариант 4: система описывает порядок организации городского спортивного соревнования.

## Что внутри

- `sql/lab2_3nf.sql` - создание базы в 3НФ (схема nf3, 10 таблиц)
- `sql/lab2_data_vault.sql` - создание хранилища Data Vault (схема dv, 8 хабов, 4 линка, 11 сателлитов)
- `schemas/` - даталогические модели обеих баз

## Как запустить

1. Создать в PostgreSQL базу, например sport_lab
2. Выполнить `sql/lab2_3nf.sql`
3. Выполнить `sql/lab2_data_vault.sql`

Делал в PostgreSQL 18, запускал через DBeaver.
